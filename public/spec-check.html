models + specs（可选 fixtures）

报告

点【自检】开始。

fixtures 怎么用（验证「字段路径有没有抄错」）

在同一份 JSON 里加一个 fixtures 块，key 可用 displayName / 客户端模型名 / capability / "*"。异步接口用 submit / poll 两段（任务 id 只在提交响应里，产物只在轮询响应里）：

"fixtures": {
  "zhipu-glm-image": {
    "submit": { "id": "task-1", "task_status": "PROCESSING" },
    "poll":   { "task_status": "SUCCESS", "image_result": [ { "url": "https://…" } ] }
  }
}

判官会逐条核对 spec 读取的每个路径，并直接告诉你 「你读的这个字段上游没有，同层有这些：…」。一次真实调用或一次文档 curl 示例就是最贵的测试数据。
